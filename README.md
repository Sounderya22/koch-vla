## Controls

| Keys | Joint |
|------|-------|
| Q / A | shoulder_pan |
| W / S | shoulder_lift |
| E / D | elbow_flex |
| R / F | wrist_flex |
| T / G | wrist_roll |
| Y / H | gripper |

`ESC` to quit.

```bash
python teleop/keyboard_teleop.py
```
